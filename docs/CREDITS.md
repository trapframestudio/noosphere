## Inspiration and Acknowledgements

Noosphere is an original co-op survival game, but the people building
it grew up on the survival sim communities that came before. This page
acknowledges the projects, communities, and creators whose work shaped
how we think about systems-driven survival design.

### S.T.A.L.K.E.R., Anomaly, and GAMMA

The S.T.A.L.K.E.R. games, the standalone mod S.T.A.L.K.E.R.: Anomaly,
and the GAMMA modpack are the works that made us want to build this
kind of game. The atmosphere, the indifference of the world, the
scavenger crafting loop, and the uncompromising design philosophy that
runs through all of them are the design lineage Noosphere draws from.

### OpenXRay

[OpenXRay](https://github.com/OpenXRay/xray-16) is an open source
continuation of the X-Ray engine. We use it as a clean-room reference
when we want to understand how a particular subsystem was approached
in a shipped survival sim. The two-tier world simulation pattern in
`simn-sim` is informed by reading OpenXRay to learn concepts. No code
is copied; the Rust implementations are written from scratch in this
repository.

### The open source community

Noosphere is built on top of an enormous amount of open source work:
the Rust language and ecosystem, the Godot engine, the godot-rust
(gdext) bindings, mdbook, and countless transitive dependencies.
Every contributor to those projects has our thanks. The dependency
manifest is the long-form version of this credit.

### Menu / Shell design system

The visual system for the shell UI (palette, type stack, component
vocabulary, Gorge backdrop, diegetic SVG icons, classification
chrome) was produced with Claude Design (claude.ai/design) working
from the Noosphere GDD. The exported HTML/CSS/JSX prototypes were
recreated as native Godot Control scenes under `godot/scenes/menus/`
and `godot/scripts/ui/`. Icons and logos live under
`godot/assets/icons/` and `godot/assets/logos/`; all were drawn from
first principles - the wordmark, roundel, and faction sigils are
placeholders flagged for replacement by final licensed art.

### Trademark caveat

Several CC-BY weapon assets carry real-world manufacturer rollmarks
(Colt, Glock text, Remington, Ruger, Mosin, Vortex, etc.). Per the
asset plan, a texture-swap pass to fictional markings is required
before ship; original provenance is preserved in each asset's
